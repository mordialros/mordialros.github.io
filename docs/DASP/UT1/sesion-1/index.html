Sesión 1. ¿Qué significa digitalizar?

1️⃣ Cambiar una herramienta no siempre cambia el proceso​

Digitalizar una organización significa utilizar tecnología y datos para cambiar o mejorar cómo trabajamos.

Cuando incorporamos tecnología, el cambio puede afectar a distintos aspectos del trabajo:

  • Digitalización de la información: pasamos información de un soporte analógico a formato digital. Esto no significa por sí solo que haya cambiado la forma de trabajar.
    Ejemplo: sustituimos un formulario en papel por el mismo formulario en PDF.

  • Digitalización de una tarea: utilizamos una herramienta digital para realizar una tarea de otra manera o de forma más eficiente.
    Ejemplo: sustituimos el PDF por un formulario web que guarda y valida automáticamente los datos.

  • Transformación de un proceso: utilizamos tecnología para cambiar cómo se coordinan varias tareas, cómo circula la información y cómo intervienen las personas o departamentos.
    Ejemplo: al enviar el formulario, los datos se registran automáticamente, llegan a las áreas implicadas y se generan las tareas necesarias.

Estos cambios no son pasos obligatorios ni tienen que darse en ese orden. Pueden aparecer por separado, de forma progresiva o al mismo tiempo.

Idea clave

Una empresa no se digitaliza simplemente porque utilice herramientas digitales.

La digitalización tiene sentido cuando la tecnología se integra en la forma de trabajar y ayuda a mejorar tareas y procesos.

2️⃣ Para mejorar algo, primero entendemos el proceso​

Un proceso es un conjunto de pasos que realizamos para conseguir un resultado.

Antes de incorporar una nueva herramienta necesitamos conocer:

qué ocurre ahora → dónde aparece el problema → qué queremos mejorar

Representar el proceso con un diagrama nos ayuda a verlo con claridad.

Ejemplo: alta de una nueva persona

Una nueva persona va a incorporarse a la empresa.

El proceso funciona actualmente así:

  1. Administración/RRHH confirma la incorporación.
  2. El responsable del área indica qué recursos necesitará la nueva persona.
  3. RRHH envía a Sistemas un correo con los datos de la incorporación y los recursos necesarios.
  4. Sistemas crea el usuario, prepara el equipo y asigna permisos.
  5. Cuando todo está preparado, comunica que puede comenzar.

El problema aparece cuando el aviso llega demasiado tarde y Sistemas no dispone de tiempo suficiente para preparar todo antes del primer día.

para pensar

¿El problema se resolvería simplemente sustituyendo el correo electrónico por otra herramienta?

¿Qué tendría que cambiar realmente en el proceso?

3️⃣ Proponemos una mejora del proceso​

Una vez que conocemos el proceso actual, podemos valorar sus puntos fuertes y débiles y detectar qué aspectos podrían mejorarse.

No se trata de incorporar tecnología porque sí, sino de preguntarnos:

  • ¿Dónde se producen retrasos?
  • ¿Qué tareas se repiten?
  • ¿Qué información llega tarde?
  • ¿Qué pasos dependen de una comunicación manual?
  • ¿Qué partes podrían coordinarse mejor?

A partir de ese análisis podemos proponer una mejora.

La propuesta puede cambiar:

  • la forma en la que se registra la información
  • el orden de algunos pasos
  • quién recibe la información y cuándo
  • la coordinación entre departamentos
  • alguna tarea que pueda simplificarse o automatizarse
Ejemplo: alta de una nueva persona

En el proceso de alta de una nueva persona hemos detectado que el principal problema aparece porque Sistemas recibe el aviso demasiado tarde.

Podemos proponer que el proceso funcione de esta forma:

  1. RRHH confirma la incorporación de la nueva persona.
  2. RRHH registra el alta en un sistema común con los datos de la incorporación y los recursos que necesitará la nueva persona.
  3. Sistemas recibe automáticamente la solicitud con antelación.
  4. Sistemas prepara el usuario, el equipo y los permisos antes de la incorporación.
  5. La nueva persona puede empezar a trabajar desde el primer día.

En este caso no nos limitamos a cambiar el correo por otra herramienta.

La mejora consiste en cambiar cuándo circula la información y coordinar mejor las tareas entre RRHH y Sistemas.

Idea clave

Primero entendemos el proceso y después pensamos la tecnología.

Una mejora tiene sentido cuando resuelve un problema concreto del proceso actual.

4️⃣ Lo aplicamos a Nexo Digital​

Durante esta unidad trabajaremos con Nexo Digital, una empresa ficticia que presta servicios tecnológicos a otras organizaciones.

La utilizaremos como contexto para aplicar los conceptos que vayamos aprendiendo en las distintas sesiones y analizar cómo puede mejorar su forma de trabajar mediante la digitalización.

En esta primera parte nos centraremos en uno de sus procesos actuales.

Cada pareja recibirá un proceso diferente y tendrá que comprender cómo funciona, representarlo y detectar qué aspectos podrían mejorarse.

Para conocer cómo funciona actualmente el proceso utilizaremos como documento de referencia Procesos de Nexo Digital.

Importante

El proceso actual no se inventa.

Partimos exclusivamente de la información proporcionada en Procesos de Nexo Digital. A partir de esa situación inicial sí podremos detectar problemas y proponer cambios.

Nuestro recorrido será:

proceso actual → problema o punto mejorable → proceso propuesto
