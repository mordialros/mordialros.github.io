1.6. Nuestro entorno de trabajo: MySQL

Hasta ahora hemos hablado de bases de datos y SGBD de forma general.

A partir de este momento vamos a situar esos conceptos en las herramientas que utilizaremos durante el curso.

Nuestro entorno de trabajo estará formado principalmente por:

  • MySQL Server, como Sistema Gestor de Bases de Datos.
  • MySQL Workbench, como aplicación cliente para conectarnos y trabajar con el servidor.
  • SQL, como lenguaje para indicar al SGBD qué operaciones queremos realizar.
RECORRIDO DE TRABAJO
🗄️ MySQL Server←→🖥️ MySQL Workbench←→⌨️ SQL

Vamos a identificar qué papel cumple cada elemento antes de empezar a utilizarlos.

1️⃣ MySQL Server: el SGBD​

MySQL Server es el software que se encarga de gestionar las bases de datos.

Es, por tanto, el SGBD de nuestro entorno de trabajo.

Entre otras tareas, se encarga de:

  • almacenar y organizar los datos.
  • recibir las peticiones que realizamos.
  • ejecutar consultas y modificaciones.
  • controlar usuarios y permisos.
  • aplicar las reglas definidas para los datos.
  • coordinar el acceso a la información.

Cuando creamos una base de datos con MySQL, los datos no se guardan dentro de Workbench: se almacenan y gestionan mediante MySQL Server.

Idea clave

MySQL Server es el SGBD.

Es el componente que realmente gestiona las bases de datos.

2️⃣ MySQL Workbench: la herramienta cliente​

MySQL Workbench es una aplicación que nos proporciona una interfaz gráfica para trabajar con MySQL Server.

Workbench no es la base de datos ni el SGBD.

Es una herramienta cliente que utilizaremos para:

  • conectarnos a un servidor MySQL.
  • escribir y ejecutar instrucciones SQL.
  • consultar información.
  • crear y modificar objetos de la base de datos.
  • visualizar algunos elementos del sistema.
  • realizar determinadas tareas de administración.

Podemos cerrar MySQL Workbench y el servidor puede seguir funcionando.

Del mismo modo, distintas herramientas podrían conectarse al mismo servidor MySQL.

Ejemplo

Podemos pensar en MySQL Workbench como una herramienta desde la que enviamos peticiones.

Cuando ejecutamos una instrucción desde Workbench:

Workbench → envía la instrucción → MySQL Server → realiza la operación

Workbench muestra después el resultado que devuelve el servidor.

3️⃣ SQL: el lenguaje que utilizaremos​

Para indicar a MySQL qué queremos hacer utilizaremos SQL (Structured Query Language).

SQL es el lenguaje con el que podremos, entre otras cosas:

  • crear estructuras para almacenar datos.
  • insertar información.
  • realizar consultas.
  • modificar datos.
  • eliminar información.
  • gestionar determinados permisos.

En el apartado 1.3 vimos que estas operaciones pueden agruparse en categorías como DDL, DML y DCL.

A partir de las próximas unidades iremos aprendiendo las instrucciones concretas de SQL de forma progresiva.

Idea clave

SQL no es un programa.

Es el lenguaje que utilizamos para comunicarnos con un SGBD relacional como MySQL.

4️⃣ ¿Cómo se relacionan los tres elementos?​

Los tres elementos de nuestro entorno cumplen funciones diferentes:

ElementoFunción
MySQL ServerEs el SGBD encargado de gestionar las bases de datos.
MySQL WorkbenchNos proporciona una interfaz para conectarnos y trabajar con el servidor.
SQLEs el lenguaje con el que indicamos al SGBD qué queremos hacer.

La base de datos es el conjunto de datos organizados sobre el que trabaja MySQL Server.

En la imagen se representa la relación entre las herramientas que utilizaremos durante el curso.

MySQL Workbench será la aplicación desde la que trabajaremos, SQL será el lenguaje con el que escribiremos las instrucciones y MySQL Server será el SGBD encargado de ejecutarlas y gestionar las bases de datos.

5️⃣ La conexión con el servidor​

Para trabajar desde MySQL Workbench necesitamos establecer una conexión con MySQL Server.

Una conexión indica a Workbench a qué servidor queremos acceder y con qué usuario.

Entre los datos habituales de una conexión encontramos:

  • el servidor o equipo al que queremos conectarnos.
  • el puerto utilizado por MySQL.
  • el usuario con el que queremos acceder.
  • la contraseña correspondiente.

Cuando servidor y cliente están instalados en el mismo ordenador, ambos programas siguen siendo componentes distintos aunque se ejecuten en la misma máquina.

Ejemplo

Si MySQL Server y MySQL Workbench están instalados en nuestro propio ordenador, Workbench se conectará al servidor que se está ejecutando en ese mismo equipo.

Si el servidor estuviera instalado en otro ordenador de la red, Workbench podría conectarse a él indicando su dirección correspondiente.

6️⃣ ¿Qué haremos con estas herramientas durante el curso?​

A lo largo del módulo iremos utilizando MySQL para recorrer las distintas etapas del trabajo con bases de datos.

Empezaremos por comprender y diseñar correctamente la información antes de construirla.

Después aprenderemos a:

  • crear bases de datos y tablas.
  • introducir y modificar datos.
  • realizar consultas.
  • relacionar información almacenada en distintas tablas.
  • controlar determinadas reglas y restricciones.
  • gestionar usuarios y permisos.
  • proteger y recuperar la información.

No necesitamos dominar ahora todas estas tareas.

En esta unidad nos basta con identificar las herramientas y comprender qué papel cumple cada una.

7️⃣ En resumen​

Nuestro entorno de trabajo estará formado principalmente por tres elementos:

  • MySQL Server, que actuará como SGBD.
  • MySQL Workbench, que utilizaremos como herramienta cliente.
  • SQL, que será el lenguaje con el que nos comunicaremos con el servidor.

La relación básica será:

MySQL Workbench → SQL → MySQL Server → Base de datos

Idea clave

No debemos confundir las herramientas:

  • MySQL Server gestiona los datos.
  • MySQL Workbench nos permite trabajar con el servidor.
  • SQL expresa las operaciones que queremos realizar.

Con este entorno preparado, ya podremos empezar a trabajar de forma práctica con las bases de datos en las siguientes unidades.
