1.2. De los ficheros a las bases de datos

En el apartado anterior hemos visto que los ficheros nos permiten conservar información y que existen distintas formas de organizarla.

Para problemas sencillos pueden ser una solución perfectamente válida.

La dificultad aparece cuando la cantidad de información aumenta, los mismos datos son necesarios en distintos lugares o varias personas y aplicaciones necesitan trabajar con ellos.

Imaginemos, por ejemplo, que una organización utiliza distintas aplicaciones y cada una mantiene sus propios ficheros.

Puede ocurrir que un mismo dato aparezca repetido varias veces, que se modifique en un fichero pero no en otro o que resulte complicado trabajar simultáneamente con la misma información.

Para afrontar este tipo de situaciones aparecen los sistemas de bases de datos.

RECORRIDO DE TRABAJO
📁 Ficheros independientes→🗃️ Datos organizados conjuntamente→⚙️ Un SGBD los gestiona→💻 Las aplicaciones acceden a través de él

Veremos qué cambia cuando dejamos de gestionar los datos mediante ficheros independientes y pasamos a utilizar un sistema de bases de datos.

1️⃣ Tres conceptos que no debemos confundir​

Cuando hablamos de sistemas de bases de datos aparecen tres conceptos relacionados, pero que no significan lo mismo.

🗃️ Base de datos​

Una base de datos es un conjunto organizado de datos relacionados entre sí que representan una parte de la realidad que necesitamos gestionar.

Los datos que almacenamos tienen un significado y responden a una necesidad concreta.

Por ejemplo, podríamos disponer de una base de datos para gestionar:

  • usuarios.
  • actividades.
  • inscripciones.
  • fechas.
  • lugares.
  • plazas disponibles.

Todos estos datos representan diferentes aspectos de una misma realidad y pueden estar relacionados entre sí.

⚙️ Sistema Gestor de Bases de Datos​

Un Sistema Gestor de Bases de Datos (SGBD) es el software que nos permite crear, mantener, consultar y gestionar una base de datos.

El SGBD actúa como intermediario entre los datos almacenados y las personas o aplicaciones que necesitan trabajar con ellos.

Esto significa que normalmente una aplicación no accede directamente a los datos almacenados, sino que solicita al SGBD la operación que necesita realizar.

🧩 Sistema de bases de datos​

Un sistema de bases de datos (SBD) integra los distintos elementos necesarios para almacenar y utilizar los datos.

En una visión sencilla podemos identificar:

  • la base de datos, donde se almacenan los datos.
  • el SGBD, encargado de gestionarlos.
  • las aplicaciones y usuarios, que trabajan con los datos a través del SGBD.

El SGBD se sitúa, por tanto, entre quienes necesitan utilizar la información y la base de datos donde esta se encuentra almacenada.

ConceptoQué representa
Base de datosLos datos organizados y relacionados.
SGBDEl software que permite gestionarlos.
Sistema de bases de datosEl entorno formado por la base de datos, el SGBD y los elementos que interactúan con ellos.
Idea clave

Una base de datos y un SGBD no son lo mismo.

La base de datos contiene los datos y el SGBD es el software que nos permite trabajar con ellos.

2️⃣ ¿Cómo cambia la forma de trabajar?​

En un sistema basado únicamente en ficheros, cada aplicación puede gestionar directamente sus propios datos.

Podríamos tener, por ejemplo:

Aplicación 1 → sus ficheros

Aplicación 2 → sus ficheros

Si distintas aplicaciones necesitan utilizar los mismos datos, estos pueden acabar duplicados en varios ficheros.

Con un sistema de bases de datos cambiamos este planteamiento.

Las aplicaciones utilizan una base de datos común y acceden a ella a través del SGBD:

De esta forma, el SGBD se convierte en el punto encargado de gestionar las peticiones realizadas sobre los datos.

Ejemplo

Supongamos que cambia el lugar de realización de una actividad.

Si distintas aplicaciones mantienen sus propios ficheros, podríamos tener que modificar ese dato en varios lugares.

Si todas trabajan con una misma base de datos, podemos mantener la información en un lugar común y las distintas aplicaciones accederán a ella a través del SGBD.

Esta forma de trabajar permite separar dos cuestiones: qué datos tenemos almacenados y qué aplicaciones los utilizan.

3️⃣ ¿Qué ganamos al utilizar una base de datos?​

Utilizar una base de datos junto con un SGBD permite resolver muchos de los problemas que aparecen cuando la información se encuentra repartida entre numerosos ficheros.

🔁 Menor redundancia

La redundancia aparece cuando almacenamos varias veces la misma información.

Una base de datos permite organizar los datos de forma que podamos reducir repeticiones innecesarias y compartir la misma información entre distintas aplicaciones.

✅ Mayor coherencia de los datos

Si un mismo dato aparece repetido en varios lugares, puede ocurrir que actualicemos una copia y olvidemos modificar las demás.

Podríamos terminar teniendo distintos valores para una información que debería ser la misma.

Al gestionar los datos de forma conjunta resulta más sencillo mantenerlos coherentes y fiables.

🔐 Mayor control de la seguridad

No todas las personas necesitan acceder a la misma información ni realizar las mismas operaciones.

El SGBD permite controlar quién puede acceder a los datos y qué puede hacer con ellos.

🔎 Distintas formas de consultar la información

Diferentes usuarios o aplicaciones pueden necesitar utilizar los mismos datos de formas distintas.

Una misma base de datos puede proporcionar la información necesaria para cada caso sin tener que crear una copia independiente de todos los datos.

🔄 Acceso simultáneo

En muchos sistemas necesitamos que varias personas o aplicaciones puedan trabajar con los datos al mismo tiempo.

El SGBD incorpora mecanismos para coordinar esos accesos y modificaciones.

Por ahora no necesitamos saber cómo lo consigue. Más adelante estudiaremos con mayor detalle qué ocurre cuando varios usuarios trabajan simultáneamente con los mismos datos.

4️⃣ ¿Todo son ventajas?​

No siempre necesitamos una base de datos.

Para guardar una cantidad pequeña de información, un fichero o una hoja de cálculo pueden resultar más sencillos y suficientes.

Utilizar un sistema de bases de datos también implica algunas dificultades.

🧩 Mayor complejidad

Necesitamos instalar y utilizar un SGBD, diseñar cómo organizaremos los datos y aprender a trabajar con las herramientas necesarias.

💻 Necesidad de recursos

Un sistema de bases de datos puede necesitar más software, almacenamiento, memoria o capacidad de procesamiento que una solución basada en unos pocos ficheros.

🎓 Necesidad de conocimientos específicos

La creación, utilización y mantenimiento de una base de datos requiere conocimientos que no son necesarios para guardar simplemente un fichero.

📁 Los ficheros pueden ser suficientes cuando...La información es sencilla, poco voluminosa y no necesitamos que muchas personas o aplicaciones trabajen con ella.
🗃️ Una base de datos resulta especialmente útil cuando...Tenemos muchos datos relacionados, necesitamos compartirlos, consultarlos de distintas formas o controlar su acceso y modificación.
Idea clave

Una base de datos no es automáticamente mejor que un fichero para cualquier problema.

Debemos elegir la forma de almacenamiento que resulte adecuada para la información que tenemos y para lo que necesitamos hacer con ella.

para pensar

Una pequeña empresa utiliza varios ficheros para guardar información sobre clientes, pedidos y productos.

  • ¿Qué problemas podrían aparecer si distintas aplicaciones utilizan copias diferentes de esos datos?
  • ¿Qué ventajas tendría utilizar una base de datos común?
  • ¿Seguiría siendo razonable usar ficheros si solo hubiera unos pocos datos y una sola persona trabajando con ellos?

Comentamos las respuestas en clase antes de continuar.

5️⃣ En resumen​

Los ficheros permiten almacenar información y siguen siendo una solución válida para muchas situaciones sencillas.

Cuando aumenta la cantidad de datos, necesitamos compartirlos entre distintas aplicaciones o usuarios, relacionarlos y mantenerlos de forma coherente, podemos utilizar un sistema de bases de datos.

En él encontramos varios elementos fundamentales:

  • la base de datos, donde se almacenan los datos organizados y relacionados.
  • el SGBD, que permite crear, consultar y gestionar esos datos.
  • las aplicaciones y usuarios, que trabajan con la información a través del SGBD.

Frente al uso de ficheros independientes, este enfoque permite reducir la redundancia, mejorar la coherencia de los datos, controlar el acceso y facilitar el trabajo simultáneo.

Sin embargo, una base de datos no siempre es la mejor solución: también implica mayor complejidad, recursos y conocimientos específicos.

Idea clave

En un sistema de bases de datos, el SGBD actúa como intermediario entre quienes utilizan la información y la base de datos donde se almacena.
