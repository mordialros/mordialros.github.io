5.2. SQL y gestión de bases de datos

Ya tenemos MySQL preparado y conocemos el modelo relacional de TechRepair. Vamos a crear la base de datos que contendrá sus tablas.

1️⃣ El lenguaje SQL​

SQL (Structured Query Language) es el lenguaje que utilizamos para comunicarnos con un SGBD relacional. Es principalmente declarativo: indicamos qué queremos hacer y el gestor determina cómo realizar la operación.

SublenguajeFinalidadEjemplos
DDL (definición de datos)Crear y modificar estructuras.CREATE, ALTER, DROP
DML (manipulación de datos)Consultar, insertar, modificar y eliminar registros.SELECT, INSERT, UPDATE, DELETE
DCL (control de datos)Gestionar los permisos de acceso.GRANT, REVOKE
TCL (control de transacciones)Controlar las transacciones.COMMIT, ROLLBACK

En esta unidad nos centraremos en DDL. Utilizaremos algunas sentencias de manipulación de datos únicamente para comprobar que las estructuras funcionan correctamente. En algunas clasificaciones, las consultas (SELECT) se agrupan por separado bajo la denominación DQL.

🔶 Elementos y normas de escritura​

Observa esta sentencia:

CREATE DATABASE techrepair
    CHARACTER SET utf8mb4;

CREATE DATABASE indica la operación, techrepair es el identificador de la base de datos y CHARACTER SET introduce una opción que concreta su configuración.

En otras sentencias encontraremos también operadores (=, >), funciones (VERSION()) y valores literales (25, 'pendiente'). Los veremos conforme los necesitemos.

Seguiremos estas convenciones:

  • Escribe las palabras reservadas de SQL en mayúsculas y los nombres de bases de datos, tablas y columnas en minúsculas.
  • Utiliza nombres descriptivos, sin espacios ni tildes; separa las palabras mediante guiones bajos (id_cliente).
  • Termina cada sentencia con punto y coma (;).
  • Utiliza saltos de línea y sangría para facilitar la lectura.
  • Escribe los comentarios con -- (deja un espacio después de los dos guiones) o entre /* y */.
Mayúsculas y minúsculas

Las palabras reservadas de SQL no distinguen entre mayúsculas y minúsculas. Sin embargo, en MySQL los nombres de bases de datos y tablas pueden distinguirlas según el sistema operativo y la configuración del servidor. Por eso utilizaremos siempre nombres en minúsculas.

Un script SQL es un archivo de texto con extensión .sql que contiene una o varias sentencias. Escríbelas en Workbench, guárdalas y utiliza Run para ejecutarlas. Recuerda que guardar un script no significa ejecutarlo.

2️⃣ Creamos una base de datos​

🔶 Crear y consultar bases de datos​

La sentencia CREATE DATABASE crea una base de datos. En MySQL, DATABASE y SCHEMA son equivalentes.

Vamos a crear la base de datos de TechRepair:

CREATE DATABASE techrepair;
SHOW DATABASES;

Actualiza el panel Schemas de Workbench y comprueba que aparece techrepair.

Si vuelves a ejecutar CREATE DATABASE techrepair;, MySQL devolverá un error porque ya existe. Para evitarlo puedes utilizar:

CREATE DATABASE IF NOT EXISTS techrepair;

Esta opción no modifica una base de datos que ya existe.

🔶 Juegos de caracteres y cotejamientos​

El juego de caracteres (character set) determina qué caracteres pueden representarse. Utilizaremos utf8mb4, que permite almacenar letras con tildes, caracteres de distintos idiomas y emojis.

El cotejamiento (collation) determina cómo se comparan y ordenan las cadenas de caracteres.

Por ejemplo, utf8mb4_0900_ai_ci utiliza utf8mb4 y, al comparar textos, no distingue los acentos (ai, accent insensitive) ni las mayúsculas y minúsculas (ci, case insensitive).

Podemos indicar ambas opciones en el momento de crear una base de datos:

CREATE DATABASE IF NOT EXISTS techrepair
    CHARACTER SET utf8mb4
    COLLATE utf8mb4_0900_ai_ci;

Como ya hemos creado techrepair, esta sentencia no cambiará sus opciones. Para consultar su configuración actual, ejecuta:

SHOW CREATE DATABASE techrepair;

🔶 Modificar una base de datos​

Si queremos establecer o cambiar sus valores predeterminados, utilizamos ALTER DATABASE:

ALTER DATABASE techrepair
    CHARACTER SET utf8mb4
    COLLATE utf8mb4_0900_ai_ci;

Vuelve a ejecutar SHOW CREATE DATABASE techrepair; y comprueba el resultado.

Valores predeterminados

El juego de caracteres y el cotejamiento de la base de datos se aplicarán por defecto a las nuevas tablas si no especificamos otros. Modificar estas opciones no convierte automáticamente las columnas de las tablas que ya existen.

3️⃣ Seleccionamos la base de datos de trabajo​

Un servidor MySQL puede gestionar varias bases de datos. Antes de crear tablas debemos indicar en cuál queremos trabajar.

USE techrepair;
SELECT DATABASE();

USE selecciona la base de datos para la conexión actual. SELECT DATABASE() permite comprobar cuál está seleccionada.

También puedes seleccionar el esquema desde el panel Schemas de Workbench, si la interfaz ofrece esa opción. Comprueba siempre el resultado con SELECT DATABASE();.

4️⃣ Eliminamos una base de datos​

DROP DATABASE elimina una base de datos y las tablas y datos que contiene. Para practicar sin afectar a TechRepair, utilizaremos una base de datos temporal:

CREATE DATABASE techrepair_pruebas;
DROP DATABASE techrepair_pruebas;
SHOW DATABASES;

Si queremos evitar el error que se produce al eliminar una base de datos inexistente, podemos utilizar:

DROP DATABASE IF EXISTS techrepair_pruebas;
Eliminar una base de datos

Antes de ejecutar DROP DATABASE, comprueba el nombre de la base de datos. Esta operación elimina su contenido. No elimines techrepair ni los esquemas internos de MySQL.

5️⃣ Creamos una base de datos con Workbench​

También podemos utilizar las herramientas gráficas para crear esquemas. En el panel Schemas, busca la opción de creación de un esquema (normalmente identificada como Create Schema).

  1. Introduce el nombre techrepair_grafico.
  2. Selecciona el juego de caracteres utf8mb4 y el cotejamiento utf8mb4_0900_ai_ci, si el formulario permite elegirlos.
  3. Si Workbench muestra el SQL generado antes de confirmar la operación, compáralo con CREATE DATABASE. Confirma la creación.
  4. Actualiza el panel de esquemas y comprueba el resultado mediante SHOW CREATE DATABASE techrepair_grafico;.
  5. Elimina únicamente el esquema de prueba con DROP DATABASE techrepair_grafico;.

La ubicación y los nombres exactos de las opciones gráficas pueden variar según la versión de Workbench. Si no encuentras el asistente, realiza esta demostración cuando se muestre en clase.

Dos formas de realizar una misma operación

Tanto si escribes una sentencia SQL como si utilizas una herramienta gráfica, es MySQL Server quien realiza la operación. El resultado debe ser equivalente.

6️⃣ Preparamos nuestro script de TechRepair​

Crea un archivo nuevo en el editor SQL y guarda este script como 01-techrepair.sql:

-- TechRepair: creación y selección de la base de datos
CREATE DATABASE IF NOT EXISTS techrepair
    CHARACTER SET utf8mb4
    COLLATE utf8mb4_0900_ai_ci;

ALTER DATABASE techrepair
    CHARACTER SET utf8mb4
    COLLATE utf8mb4_0900_ai_ci;

USE techrepair;

Ejecuta el script y comprueba con SELECT DATABASE(); y SHOW CREATE DATABASE techrepair; que la base de datos está preparada. Todavía no vamos a crear las tablas.
