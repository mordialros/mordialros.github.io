5.0. Preparación del entorno de trabajo

Antes de comenzar a implementar TechRepair, necesitas preparar tu entorno de trabajo. Instalaremos MySQL Server y MySQL Workbench en el propio ordenador y comprobaremos que funcionan correctamente.

1️⃣ Recordamos nuestro entorno de trabajo​

Como vimos en la UT1. Nuestro entorno de trabajo: MySQL, cada elemento cumple una función diferente:

ElementoFunción
MySQL ServerAlmacena y gestiona los datos, ejecuta las sentencias SQL y aplica las restricciones.
MySQL WorkbenchEs el cliente gráfico desde el que trabajamos con el servidor.
SQLEs el lenguaje que utilizamos para comunicarnos con el SGBD.

Ambas aplicaciones estarán instaladas en el mismo ordenador. Workbench se conectará al servidor local (localhost o 127.0.0.1) mediante el puerto 3306.

importante

Instalar Workbench no equivale a instalar MySQL Server. Cerrar Workbench tampoco detiene el servidor ni elimina las bases de datos.

2️⃣ Instalación de MySQL Server​

Realizaremos una instalación estándar en Windows de 64 bits. Las capturas de esta guía corresponden a MySQL Community Server 8.4.13 LTS (paquete de descarga 8.4.13.1) y MySQL Workbench 26.10.0.

Antes de comenzar la instalación

Si ya tienes MySQL Server instalado, comprueba su versión y funcionamiento. Si funciona correctamente y es compatible con MySQL Workbench, no necesitas volver a instalarlo. No elimines instalaciones ni bases de datos existentes.

  • Si utilizas Linux o macOS: descarga los paquetes correspondientes a tu sistema operativo y sigue las instrucciones de la documentación oficial de MySQL.
  • Si el puerto 3306 está ocupado: durante la configuración del servidor aparecerá un error. En ese caso, selecciona otro puerto disponible, por ejemplo, el 3307. Recuerda utilizar ese mismo puerto al configurar la conexión en MySQL Workbench.

🔶 Descarga e instalación​

  1. Accede a MySQL Community Server.
  2. Selecciona la rama 8.4 LTS, el sistema Microsoft Windows y el instalador Windows (x86, 64-bit), MSI Installer. Pulsa Download.
  1. Si se solicita iniciar sesión o registrarse, pulsa No thanks, just start my download.
  2. Ejecuta el archivo MSI, pulsa Next, acepta la licencia y selecciona el tipo de instalación Typical.
  1. Pulsa Install para instalar el servidor. Al finalizar, deja marcada la opción Run MySQL Configurator y pulsa Finish.

🔶 Configuración del servidor​

Se abrirá MySQL Configurator. Pulsa Next en la pantalla de bienvenida y conserva la ruta predeterminada de Data Directory.

En Type and Networking, mantén el perfil Development Computer, TCP/IP activado y los puertos predeterminados (3306 y 33060). Desmarca Open Windows Firewall ports for network access, puesto que trabajaremos desde el propio equipo. Deja el resto de opciones sin modificar.

En Accounts and Roles, establece y confirma una contraseña segura para root, la cuenta de administración del servidor. No añadas usuarios adicionales en este paso. Conserva la contraseña en un lugar seguro y no la incluyas en las entregas.

En Windows Service, conserva las opciones predeterminadas: servicio MySQL84, inicio automático al arrancar Windows y Standard System Account.

Continúa con las siguientes pantallas:

  • Server File Permissions: conserva la primera opción, que limita el acceso a los archivos del servidor.
  • Sample Databases: deja desmarcadas las bases de datos Sakila y World.

En Apply Configuration, pulsa Execute. Comprueba que todas las operaciones finalizan correctamente, pulsa Next y termina con Finish.

MySQL Server ya está instalado y en funcionamiento.

3️⃣ Instalación de MySQL Workbench​

  1. Accede a MySQL Workbench.
  2. Selecciona la versión 26.10.0 (o una revisión posterior compatible indicada por el docente), Microsoft Windows y el instalador Windows (x86, 64-bit), MSI Installer.
  1. Descarga y ejecuta el instalador. Pulsa Next.
  2. En Installation Scope, selecciona Install just for you, para instalar Workbench únicamente en tu cuenta de Windows.
  1. Continúa con la instalación conservando las opciones predeterminadas. Al finalizar, deja marcada Run MySQL Workbench y pulsa Finish.

4️⃣ Conectamos Workbench con MySQL Server​

En la pantalla inicial, pulsa el botón + junto a Database Connections para crear una conexión.

En Database Connection Configuration, introduce los siguientes valores:

CampoValor
CaptionMySQL Local
DescriptionServidor MySQL local para GBD
Connection Methodmysql
User Nameroot
Host Name or IP Addresslocalhost
Port3306
Default SchemaDejar vacío
Factor 1password
Factor 2 y Factor 3None

Deja el resto de opciones con sus valores predeterminados.

Pulsa Test Connection e introduce la contraseña de root que estableciste durante la configuración del servidor. No es necesario guardarla en Workbench.

Si los datos son correctos, aparecerá el siguiente mensaje:

Pulsa OK para guardar la conexión y abre MySQL Local. Introduce la contraseña si se solicita.

5️⃣ Primeros pasos en Workbench​

Una vez conectado, identifica las principales zonas del entorno de trabajo:

ZonaFunción
AdministrationHerramientas de administración del servidor.
SchemasExplorar las bases de datos y sus objetos.
Editor SQLEscribir y editar sentencias SQL.
RunEjecutar sentencias SQL.
OutputConsultar los mensajes de ejecución y errores.
ConnectedComprobar el estado de la conexión.

🔶 Comprobamos el funcionamiento​

Escribe las siguientes sentencias en el editor SQL:

SELECT VERSION();
SHOW DATABASES;

Selecciona las sentencias y pulsa Run para ejecutarlas. Los resultados se muestran en pestañas de resultados independientes; selecciona cada una para consultarlos.

  • SELECT VERSION(); muestra la versión de MySQL Server, no la de Workbench.
  • SHOW DATABASES; muestra las bases de datos visibles para la cuenta con la que te has conectado.

No modifiques ni elimines los esquemas internos de MySQL (mysql, information_schema, performance_schema, sys).

Guarda las dos sentencias mediante File → Save (o Ctrl + S) en un archivo llamado 00-comprobacion-entorno.sql.

Un script SQL es un archivo de texto que contiene sentencias SQL. Guardar un script y ejecutar sus sentencias son operaciones diferentes.

6️⃣ Comprueba que todo está preparado​

  • Tengo MySQL Server y MySQL Workbench instalados.
  • Puedo conectarme al servidor local.
  • He ejecutado las dos sentencias y guardado mi primer script.
  • Puedo cerrar Workbench, abrirlo de nuevo y volver a conectarme.

Si no puedes conectarte, comprueba que el servicio MySQL84 está iniciado (puedes buscarlo en Servicios de Windows), que el puerto coincide con el configurado y que el usuario y la contraseña son correctos.

Antes de continuar, asegúrate de que sabes explicar qué diferencia hay entre MySQL Server y MySQL Workbench y qué ocurriría si el servidor estuviera detenido.
