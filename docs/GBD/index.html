Gestión de Bases de Datos

1.º ASIR · Curso 2026-2027

Las bases de datos están detrás de gran parte de los sistemas y servicios que utilizamos cada día: aplicaciones, páginas web, plataformas educativas, tiendas online, servicios de streaming o sistemas de gestión.

En este módulo aprenderemos a organizar, almacenar y utilizar información de forma estructurada, comprendiendo primero cómo debe organizarse antes de empezar a trabajar con ella.

A lo largo del curso recorreremos todo el proceso: desde analizar una necesidad y decidir cómo organizar sus datos hasta construir la base de datos, obtener información de ella, modificarla y protegerla frente a errores o pérdidas.

1️⃣ ¿Qué aprenderemos?​

Aprenderemos a trabajar con los datos desde diferentes puntos de vista.

A lo largo del curso iremos aprendiendo a:

  • comprender para qué sirven las bases de datos y cómo se gestionan;
  • analizar una situación y decidir qué información necesitamos almacenar;
  • organizar esa información antes de empezar a construir;
  • transformar nuestras ideas en una estructura que pueda utilizar un sistema informático;
  • crear y modificar bases de datos;
  • buscar y obtener la información que necesitamos;
  • relacionar datos procedentes de diferentes partes de la base de datos;
  • añadir, modificar y eliminar información de forma segura;
  • controlar operaciones en las que intervienen varios cambios;
  • proteger la información frente a errores o pérdidas;
  • realizar copias y recuperar los datos cuando sea necesario.
Idea clave

Una base de datos no comienza escribiendo instrucciones en el ordenador.

Antes tenemos que comprender el problema, decidir qué información necesitamos y pensar cómo organizarla.

2️⃣ ¿Cómo vamos a trabajar?​

Trabajaremos de forma principalmente práctica y progresiva.

Cada nuevo concepto se introducirá mediante explicaciones y ejemplos sencillos y, a partir de ellos, iremos resolviendo situaciones cada vez más completas.

Durante el curso trabajaremos mediante:

  • explicaciones breves de los conceptos fundamentales;
  • ejemplos y ejercicios guiados;
  • prácticas individuales;
  • resolución de casos y pequeños supuestos;
  • diseño y organización de información;
  • trabajo práctico con bases de datos;
  • análisis de errores y corrección de soluciones;
  • comparación de diferentes formas de resolver un mismo problema;
  • prácticas progresivamente más autónomas.

No bastará con conseguir que algo funcione.

Tendremos que aprender a entender qué estamos haciendo, por qué funciona y si la solución que hemos elegido es adecuada.

Una pregunta que repetiremos durante el curso

¿Qué información necesitamos y cómo debemos organizarla para poder trabajar con ella?

3️⃣ ¿Con qué vamos a trabajar?​

Nuestro sistema gestor principal será MySQL.

Utilizaremos principalmente:

  • MySQL Server, donde estarán almacenadas y gestionadas nuestras bases de datos;
  • MySQL Workbench, como herramienta gráfica para diseñar y trabajar con ellas;
  • el lenguaje SQL, que utilizaremos para comunicarnos con la base de datos;
  • progresivamente, algunas herramientas de línea de comandos.

También veremos ejemplos con otros sistemas gestores para comprobar que los conceptos que aprenderemos pueden aplicarse en diferentes entornos.

SQL no es MySQL

  • SQL es el lenguaje que utilizaremos para comunicarnos con bases de datos relacionales.

  • MySQL es uno de los sistemas gestores que podemos utilizar para trabajar con ellas.

4️⃣ Nuestro recorrido​

A lo largo del curso seguiremos un recorrido progresivo que nos llevará desde una situación en la que simplemente tenemos información que necesitamos organizar hasta ser capaces de trabajar con una base de datos completa.

Visión general del recorrido
📥 Reunimos información→🧠 La pensamos y la organizamos→🛠️ Construimos la base de datos→🔎 Trabajamos con ella (consultamos · relacionamos · modificamos)→🛡️ La protegemos y la recuperamos

Aprenderemos, paso a paso, cómo pasar de tener información dispersa a ser capaces de organizarla, utilizarla y protegerla.

UT1. Houston, tenemos datos

Introducción a las bases de datos y los SGBD

Empezaremos entendiendo qué es realmente una base de datos y por qué necesitamos herramientas específicas para gestionar grandes cantidades de información.

Veremos cómo hemos pasado de guardar datos de forma aislada a utilizar sistemas capaces de organizarlos, compartirlos y mantenerlos de forma segura.

La primera pregunta será: Tenemos muchos datos... ¿qué hacemos con ellos?

UT2. Antes de actuar, hay que meditar

Diseño conceptual: modelo entidad-relación

Antes de construir nada tendremos que comprender bien el problema que queremos resolver.

Aprenderemos a analizar una situación, descubrir qué información necesitamos guardar y representar de forma clara cómo se relacionan unos datos con otros.

En esta unidad todavía no construiremos la base de datos.

Primero tendremos que pensar y diseñar.

UT3. Cada cosa en su sitio

Modelo relacional y normalización

Una vez que sabemos qué información necesitamos, tendremos que decidir cómo organizarla correctamente.

Aprenderemos a pasar de nuestro diseño inicial a una estructura ordenada, evitando repeticiones innecesarias y problemas que podrían aparecer más adelante.

El objetivo será conseguir que cada dato esté donde debe estar.

UT4. Manos a la obra

Diseño físico y lenguaje DDL

Hasta ahora habremos analizado, pensado y organizado.

En esta unidad llegará el momento de construir realmente nuestra base de datos.

Crearemos su estructura, decidiremos qué tipo de información podrá almacenarse y estableceremos reglas para impedir que se introduzcan datos incorrectos o incoherentes.

Pasaremos del diseño a una base de datos que ya podremos utilizar.

UT5. Pregúntame lo que quieras

Consultas SQL básicas

Guardar información sirve de poco si después no podemos encontrar lo que necesitamos.

Aprenderemos a hacer preguntas a nuestra base de datos y conseguir que nos devuelva únicamente la información que buscamos.

Empezaremos con preguntas sencillas y poco a poco seremos capaces de obtener resultados cada vez más precisos.

UT6. Elemental, querido SQL

Consultas SQL avanzadas

Las preguntas empezarán a complicarse.

Muchas veces la información necesaria estará repartida en distintos lugares y tendremos que investigar cómo relacionarla para obtener una respuesta.

Aprenderemos a resolver problemas cada vez más completos y veremos que puede existir más de una forma correcta de llegar al mismo resultado.

UT7. Nada es para siempre

Inserción, modificación y eliminación de datos

Los datos de una aplicación real no permanecen siempre iguales.

Se crean nuevos registros, algunos cambian y otros dejan de ser necesarios.

Aprenderemos a añadir, actualizar y eliminar información de forma controlada, comprobando siempre qué consecuencias tendrán nuestros cambios antes de realizarlos.

UT8. Todo o nada

Transacciones, concurrencia y programación en la base de datos

Hay situaciones en las que varias operaciones forman parte de una misma acción y necesitamos asegurarnos de que todo termina correctamente.

También veremos qué puede ocurrir cuando varias personas o aplicaciones intentan trabajar al mismo tiempo con la misma información.

El objetivo será aprender a realizar operaciones de forma segura, coherente y controlada.

UT9. Que no cunda el pánico

Copias de seguridad, recuperación e intercambio de datos

Hasta una base de datos bien diseñada puede sufrir un fallo, un error humano o una pérdida de información.

Terminaremos el curso aprendiendo a proteger nuestros datos y estar preparados para recuperarlos cuando algo salga mal.

También veremos cómo podemos trasladar información de un sistema a otro.

La idea será sencilla: si algo falla, debemos estar preparados.
