1.5. Arquitecturas, capas y protocolos

Ya sabemos cómo se organizan físicamente las redes. Ahora vamos a ver cómo se organiza la comunicación: qué normas siguen los equipos para entenderse y por qué esas normas se reparten en capas.

1️⃣ ¿Qué es un protocolo?​

Un protocolo de comunicación es un conjunto de reglas que define cómo se intercambia la información entre dos o más equipos.

Un protocolo establece tres cosas:

  • El formato (sintaxis): cómo se estructura la información y qué datos lleva cada parte.
  • El significado (semántica): qué quiere decir cada dato y qué hay que hacer al recibirlo.
  • El orden y los tiempos (temporización): quién habla primero, cuándo se responde y qué pasa si no llega respuesta.
Ejemplo

Enviar una carta también sigue un protocolo. El formato: el destinatario va en el centro del sobre y el remitente en el reverso. El significado: el sello indica que el envío está pagado. El orden: primero se escribe la carta, después se mete en el sobre y por último se deposita en el buzón. Si alguien escribe la dirección en otro lugar, el sistema postal no sabrá qué hacer con ella.

Algunos protocolos que irán apareciendo durante el módulo:

ProtocoloPara qué sirve
EthernetEnviar información dentro de una red local cableada
IPHacer llegar la información de una red a otra hasta su destino
TCP y UDPEntregar la información a la aplicación correcta
HTTP / HTTPSSolicitar y enviar páginas web
DNSTraducir nombres como www.ejemplo.com a direcciones IP

2️⃣ ¿Por qué se organiza la comunicación en capas?​

Enviar información por una red es un problema muy complejo: hay que convertir los datos en señales, encontrar el camino, corregir errores, entregarlos a la aplicación adecuada… Para abordarlo, se divide en partes más pequeñas, llamadas capas o niveles.

  • Cada capa se encarga de una tarea concreta.
  • Cada capa ofrece un servicio a la capa superior y se apoya en la inferior, sin necesidad de saber cómo funciona por dentro.
  • Se puede cambiar una capa sin afectar a las demás: por ejemplo, pasar de cable a Wi‑Fi sin cambiar el navegador.
  • Permite que fabricantes distintos desarrollen productos compatibles, cada uno centrado en una capa.
Ejemplo

Una empresa de mensajería funciona por capas. Quien escribe el paquete no sabe qué camión lo llevará; el conductor no sabe qué contiene; la persona del almacén solo mira la dirección para clasificarlo. Cada uno hace su parte y confía en los demás. Si la empresa cambia los camiones por furgonetas eléctricas, nadie más tiene que cambiar su forma de trabajar.

Al conjunto de capas y protocolos que organiza la comunicación lo llamamos arquitectura de red. Las dos más importantes son el modelo OSI y el modelo TCP/IP.

3️⃣ El modelo OSI​

El modelo OSI fue creado por la ISO (Organización Internacional de Normalización) como modelo de referencia: describe en siete capas todo lo que debe ocurrir en una comunicación.

CapaNombreQué hace, en una frase
7AplicaciónOfrece los servicios de red a las aplicaciones del usuario
6PresentaciónSe ocupa del formato de los datos: codificación, cifrado, compresión
5SesiónAbre, mantiene y cierra el diálogo entre las aplicaciones
4TransporteEntrega los datos a la aplicación correcta y controla que lleguen bien
3RedBusca el camino entre redes distintas, usando direcciones IP
2Enlace de datosEntrega los datos dentro de la misma red local, usando direcciones MAC
1FísicaTransmite los bits como señales por el medio: cable, fibra o aire

4️⃣ El modelo TCP/IP​

El modelo TCP/IP es el que funciona realmente en Internet. Es más sencillo y agrupa las funciones en cuatro capas:

Capa TCP/IPCorresponde en OSI aProtocolos de ejemplo
AplicaciónAplicación, presentación y sesión (7, 6, 5)HTTP, DNS, correo
TransporteTransporte (4)TCP, UDP
InternetRed (3)IP
Acceso a la redEnlace de datos y física (2, 1)Ethernet, Wi‑Fi
Idea clave

OSI es el modelo de referencia que usamos para explicar y para localizar problemas («es un fallo de capa 2»). TCP/IP es el modelo que se usa en la práctica. En esta unidad nos basta con este mapa general; en la UT2 veremos cómo viaja la información de capa en capa.
