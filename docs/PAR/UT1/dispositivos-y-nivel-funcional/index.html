1.6. Elementos de una red y nivel funcional

En la UT0 aprendimos a reconocer los dispositivos que aparecen en una red. Ahora vamos a relacionarlos con las funciones de las capas OSI: qué tarea realiza cada dispositivo y qué información utiliza para llevarla a cabo.

No todos los dispositivos trabajan del mismo modo. Algunos se limitan a transmitir señales, mientras que otros examinan información de la comunicación para decidir cómo reenviarla.

1️⃣ Elementos físicos y elementos lógicos​

Una red necesita tanto componentes que podemos tocar como información y reglas que hacen posible su funcionamiento.

Elementos físicosElementos lógicos
Dispositivos finales: ordenadores, servidores e impresoras.Protocolos: reglas que permiten intercambiar información.
Interfaces o tarjetas de red (NIC - Network Interface Card): permiten conectar los equipos.Direcciones: identificadores, como MAC e IP, utilizados en diferentes funciones de comunicación.
Medios de transmisión: cables, fibra óptica o medios inalámbricos.Configuración de red: parámetros, como la dirección IP o la puerta de enlace.
Dispositivos de interconexión: switches, routers y puntos de acceso.Software y servicios de red: programas y funciones que participan en la comunicación.

Esta clasificación nos ayuda a estudiar la red, aunque en la práctica los elementos físicos funcionan gracias al software y a la configuración que utilizan.

Ejemplo

Podemos conectar dos ordenadores a un switch mediante cables y conseguir que los indicadores de enlace se enciendan. Sin embargo, eso no garantiza por sí solo que una prueba de comunicación IP entre ambos equipos funcione: también debemos comprobar su configuración.

2️⃣ Los dispositivos y su nivel funcional​

En el apartado anterior hemos estudiado que el modelo OSI organiza las funciones de comunicación en siete capas. Ahora vamos a relacionar esas funciones con los dispositivos que podemos encontrar en una red.

El nivel funcional de un dispositivo indica con qué capa del modelo OSI se relaciona principalmente su funcionamiento.

La siguiente tabla resume los principales dispositivos y las capas con las que se relacionan:

DispositivoSímboloNivel funcional principalFunción
Repetidor—Capa 1. FísicaRegenera o retransmite señales para ampliar el alcance de una conexión.
Hub (concentrador)—Capa 1. FísicaRepite las señales que recibe por un puerto hacia los demás.
Switch (conmutador)Capa 2. Enlace de datosConecta dispositivos de una red local y utiliza direcciones MAC para dirigir la información.
Punto de acceso (AP)Principalmente capa 2. Enlace de datosPermite conectar dispositivos inalámbricos a una red.
Router (encaminador)Capa 3. RedConecta redes diferentes y utiliza direcciones IP para dirigir la información hacia otras redes.
Host (ordenador, servidor, etc.)Puede utilizar todas las capasEnvía y recibe información y ejecuta aplicaciones que utilizan la red.
Idea clave

Los dispositivos se relacionan con diferentes capas OSI según la función que realizan:

  • Capa 1. Física: dispositivos que trabajan principalmente con señales, como los repetidores y los hubs.
  • Capa 2. Enlace de datos: dispositivos como los switches, que utilizan direcciones MAC.
  • Capa 3. Red: dispositivos como los routers, que utilizan direcciones IP.

Esta clasificación nos ayuda a comprender su funcionamiento, aunque algunos dispositivos actuales pueden realizar funciones de varias capas.

🔶 Hub y switch: dos formas distintas de conectar equipos​

Un hub y un switch permiten conectar varios equipos en una red local, pero funcionan de manera diferente.

El hub recibe señales por uno de sus puertos y las repite hacia todos los demás, sin distinguir a qué equipo va dirigida la información.

El switch, en cambio, puede identificar por qué puerto se encuentra conectado un dispositivo y utilizar esa información para dirigir las comunicaciones de forma más eficiente.

Ejemplo

Imaginemos un aula con cuatro ordenadores conectados a un dispositivo central.

  • Con un hub: cuando un ordenador transmite información, el dispositivo repite las señales hacia los demás ordenadores.
  • Con un switch: cuando un ordenador quiere comunicarse con otro, el dispositivo puede dirigir la información hacia el puerto correspondiente, si conoce dónde se encuentra el destinatario.

Por este motivo, en las redes locales actuales utilizamos normalmente switches en lugar de hubs.

El switch utiliza para ello las direcciones MAC, que estudiaremos en el siguiente apartado.

Más adelante, en la UT6, veremos con detalle cómo aprende un switch dónde están conectados los equipos y cómo gestiona las comunicaciones.

🔶 El router: comunicación entre redes​

Un router es un dispositivo que permite conectar redes diferentes y dirigir la información entre ellas.

Mientras que un switch se utiliza habitualmente para conectar los equipos de una misma red local, un router permite que esa red se comunique con otras.

Para realizar esta función utiliza las direcciones IP, que permiten identificar los equipos y su ubicación lógica dentro de las redes.

Ejemplo

En un instituto tenemos varios ordenadores conectados a un switch.

Si dos ordenadores de la misma red local quieren comunicarse, pueden hacerlo a través del switch, sin necesidad de que el router intervenga en esa comunicación.

Sin embargo, cuando uno de esos ordenadores quiere acceder a una página web de Internet, normalmente necesita utilizar el router para comunicarse con redes externas.

El router suele actuar como puerta de enlace predeterminada, es decir, el dispositivo al que un equipo envía normalmente la información destinada a otras redes.

En el siguiente apartado estudiaremos qué son las direcciones IP y cómo se diferencian de las direcciones MAC.

🔶 Otros elementos que conviene conocer​

Además de los dispositivos anteriores, existen otros componentes que participan en las comunicaciones de red:

  • Tarjeta de red (NIC): componente que permite conectar un equipo a una red, por ejemplo, mediante Ethernet o Wi-Fi. NIC son las siglas de Network Interface Card.
  • Módem: dispositivo que adapta las señales para determinadas tecnologías de acceso a una red, como algunas conexiones de telefonía o cable.
  • Cortafuegos (firewall): sistema de hardware o software que controla las comunicaciones de red mediante reglas de seguridad, permitiendo o bloqueando determinadas conexiones.
El «router» doméstico

El dispositivo que habitualmente llamamos «router de casa» suele integrar varias funciones en un mismo equipo:

  • Router: conecta nuestra red local con otras redes, como Internet.
  • Switch: permite conectar equipos mediante cables Ethernet.
  • Punto de acceso Wi-Fi: permite conectar dispositivos inalámbricos.

Dependiendo de la tecnología utilizada para acceder a Internet, también pueden necesitarse otros dispositivos, como una ONT (Optical Network Terminal o Terminal de Red Óptica), que permite conectar la fibra óptica del operador con el router. La ONT puede ser un dispositivo independiente o estar integrada en el propio router.

En redes de empresas o centros educativos, estas funciones pueden estar repartidas entre distintos dispositivos.

para pensar

En un aula de informática tenemos varios ordenadores conectados a un switch. Este switch está conectado a un router que proporciona acceso a Internet.

  1. ¿Por qué utilizamos un switch para conectar los ordenadores del aula en lugar de un hub?
  2. ¿Qué función cumple el router que no realiza normalmente un switch de capa 2?
  3. ¿Con qué capa OSI relacionamos principalmente cada uno de estos dispositivos?

Justifica tus respuestas a partir de las funciones que realiza cada dispositivo.
