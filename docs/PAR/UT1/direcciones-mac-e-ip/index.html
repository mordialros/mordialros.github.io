1.7. Direcciones MAC e IP

En el apartado anterior hemos visto que un switch y un router realizan funciones diferentes. Para dirigir la información utilizan distintos tipos de direcciones: MAC e IP. Vamos a conocer qué identifica cada una y por qué son necesarias.

1️⃣ Dos direcciones, dos funciones​

Cuando un equipo se conecta a una red, necesitamos poder identificar su conexión para que pueda intercambiar información con otros equipos. Para comprender cómo lo hacemos, primero debemos conocer un elemento fundamental: la interfaz de red.

🔶 ¿Qué es una interfaz de red?​

Una interfaz de red es el elemento a través del cual un dispositivo se conecta y se comunica con una red. Puede corresponder a un componente físico, como una tarjeta Ethernet o un adaptador Wi-Fi, o ser una interfaz virtual creada mediante software.

Un mismo equipo puede disponer de varias interfaces. Por ejemplo, un portátil puede utilizar:

  • Una interfaz Ethernet, para conectarse mediante un cable de red.
  • Una interfaz Wi-Fi, para conectarse de forma inalámbrica.

Cada una de estas interfaces tiene normalmente su propia dirección MAC y puede tener una dirección IP configurada. Por tanto, no debemos pensar que todos los dispositivos tienen una única dirección para todas sus conexiones.

Las direcciones mostradas son ilustrativas: no significa que ambas conexiones deban estar activas a la vez ni que siempre reciban esas direcciones.

🔶 ¿Para qué sirven las direcciones MAC e IP?​

Aunque ambas aparecen en las conexiones de red, tienen funciones diferentes:

  • La dirección MAC se utiliza para identificar interfaces en tecnologías de red local como Ethernet o Wi-Fi.
  • La dirección IP identifica una interfaz dentro de una red IP y permite dirigir la información hacia su destino, incluso cuando intervienen redes distintas.
Idea clave

MAC e IP no son dos nombres para la misma dirección. La dirección MAC se relaciona principalmente con la capa 2 (Enlace de datos) del modelo OSI, mientras que la dirección IP se relaciona con la capa 3 (Red).

En los siguientes apartados veremos sus características, formatos y diferencias.

2️⃣ La dirección MAC​

Una dirección MAC (Media Access Control) es un identificador utilizado por las interfaces de red en tecnologías como Ethernet y Wi-Fi.

  • Habitualmente tiene 48 bits y se representa mediante 12 cifras hexadecimales, por ejemplo: 00:1A:2B:3C:4D:5E.
  • Suele venir asignada por el fabricante de la interfaz de red, aunque puede modificarse o sustituirse por otra dirección en determinadas circunstancias.
  • Se utiliza en la comunicación local, dentro de tecnologías como Ethernet o Wi-Fi. Por ejemplo, un switch puede utilizar direcciones MAC para dirigir la información dentro de una LAN.
  • Un ordenador puede tener varias interfaces de red (por ejemplo, Ethernet y Wi-Fi) y, por tanto, varias direcciones MAC.
¿Qué significa hexadecimal?

El sistema hexadecimal utiliza 16 símbolos: del 0 al 9 y de la A a la F. Cada cifra hexadecimal representa 4 bits. Por eso, una dirección MAC de 12 cifras hexadecimales tiene 48 bits.

No necesitamos convertir entre hexadecimal y binario en esta unidad.

Ejemplo

Un portátil tiene una interfaz Ethernet para conectarse por cable y otra Wi-Fi para conectarse de forma inalámbrica. Cada una puede tener su propia dirección MAC.

Por eso, es más preciso decir que la MAC identifica una interfaz de red que afirmar que identifica de forma única y permanente a todo el ordenador.

3️⃣ La dirección IP​

Una dirección IP identifica una interfaz en una red que utiliza el protocolo IP. Permite que los dispositivos y routers sepan hacia dónde deben dirigir la información, incluso cuando el origen y el destino pertenecen a redes diferentes.

  • No es un identificador fijo grabado en el equipo: se configura en la interfaz de red.
  • Puede asignarse manualmente o de forma automática, por ejemplo mediante DHCP, un servicio que proporciona direcciones y otros parámetros de configuración de red.
  • Puede cambiar al conectar el equipo a otra red, aunque también puede mantenerse si se ha establecido una configuración fija.
  • Su formato depende de la versión del protocolo IP utilizada. Por ejemplo, en IPv4 se representa mediante cuatro números separados por puntos, como 192.168.1.25.
Ejemplo

Un portátil puede tener la dirección IP 192.168.1.25 cuando se conecta a la red de casa y otra dirección IP al conectarse a la red del instituto.

Esto no exige cambiar la tarjeta de red: la dirección IP depende de la configuración de la conexión.

🔶 Versiones del protocolo IP​

Existen dos versiones principales del protocolo IP:

  • IPv4 (Internet Protocol version 4): utiliza direcciones de 32 bits, representadas mediante cuatro números del 0 al 255 separados por puntos. Por ejemplo, 192.168.1.25.
  • IPv6 (Internet Protocol version 6): utiliza direcciones de 128 bits, representadas mediante grupos de caracteres hexadecimales separados por dos puntos. Por ejemplo, 2001:db8::1.

IPv6 surgió para ampliar considerablemente la cantidad de direcciones disponibles, ya que el espacio de direcciones de IPv4 es limitado.

En nuestras primeras prácticas utilizaremos IPv4. Más adelante estudiaremos en detalle ambas versiones: IPv4 en la UT4 e IPv6 en la UT5.

🔶 Direcciones IPv4 privadas y públicas​

En IPv4 distinguimos, entre otras, las direcciones privadas y las direcciones públicas:

  • Privadas: están reservadas para utilizarse en redes internas. No se encaminan directamente por Internet. Pertenecen a tres rangos: 10.0.0.0–10.255.255.255, 172.16.0.0–172.31.255.255 y 192.168.0.0–192.168.255.255.
  • Públicas: son direcciones que pueden utilizarse para identificar interfaces accesibles mediante el direccionamiento público de Internet, siempre que la conexión y las reglas de red lo permitan. No todas las direcciones que no son privadas son necesariamente públicas utilizables.
Ejemplo

En una red doméstica, un ordenador puede tener la IP privada 192.168.1.25. El router puede utilizar una dirección pública para comunicarse con Internet, aunque algunas conexiones de operadores utilizan configuraciones adicionales.

La relación entre direcciones privadas, públicas y la salida a Internet la estudiaremos con más detalle en unidades posteriores.

En la UT4 aprenderemos cómo se estructuran las direcciones IPv4, para qué sirve la máscara y cómo se dividen las redes. En la UT5 conoceremos IPv6.

La relación entre MAC y switch e IP y router indica qué tipo de dirección utiliza principalmente cada dispositivo para dirigir la información. No significa que un switch solo utilice direcciones MAC ni que un router solo utilice direcciones IP.

Idea clave

Cuando dos equipos se comunican, las direcciones IP permiten identificar el origen y el destino en la red IP, mientras que las direcciones MAC se utilizan en los enlaces locales que emplean esta tecnología.

No es necesario conocer todavía cómo se combinan ambas direcciones durante el envío de información. Lo analizaremos al estudiar las comunicaciones y los protocolos con mayor profundidad.
