🔄 UT0. Volver a conectar

Después de un tiempo sin trabajar con bases de datos, algunos conceptos pueden haberse quedado un poco olvidados.

Antes de comenzar con la administración de sistemas gestores de bases de datos, vamos a recuperar los conocimientos fundamentales de bases de datos relacionales y SQL que necesitaremos durante el curso.

info

No se trata de volver a estudiar todo lo visto en primero.

El objetivo es recordar los conceptos esenciales y volver a utilizarlos mediante ejemplos prácticos.

1️⃣ ¿Qué vamos a recordar?​

  • Cómo se representa un problema mediante un modelo entidad-relación.

  • Cómo se transforma ese modelo en tablas, claves y relaciones.

  • Cómo trabajar con los datos mediante SQL.

  • Cómo realizar consultas sobre una o varias tablas.

  • Cómo obtener información resumida mediante agrupaciones.

  • Cómo utilizar subconsultas.

  • Cómo modificar los datos de forma segura.

  • Cómo utilizar transacciones básicas.

2️⃣ Materiales y herramientas​

Durante esta unidad utilizaremos distintas herramientas para diseñar, implementar y consultar bases de datos.

🔸 Diagramas E/R y modelo relacional​

Para representar gráficamente el diseño utilizaremos diagrams.net (draw.io).

Nos permitirá crear:

  • entidades, atributos y relaciones;
  • cardinalidades;
  • tablas y columnas;
  • claves primarias y foráneas;
  • relaciones entre tablas.
Guarda también el archivo editable

Además de exportar el diagrama como imagen, guarda el archivo original de diagrams.net (.drawio).

Así podrás modificarlo posteriormente sin tener que volver a construirlo.

🔸 MySQL Server​

Utilizaremos MySQL Server como sistema gestor de bases de datos.

Será el encargado de:

  • almacenar las bases de datos;
  • ejecutar las instrucciones SQL;
  • comprobar las restricciones;
  • mantener las relaciones entre los datos;
  • y gestionar las transacciones.

Para Windows, puede instalarse utilizando MySQL Installer, que permite instalar y configurar los distintos componentes de MySQL.

👉 Descargar MySQL Installer para Windows

También puede descargarse MySQL Community Server directamente desde:

👉 Descargar MySQL Community Server

🔸 MySQL Workbench​

Utilizaremos MySQL Workbench como herramienta gráfica para conectarnos a MySQL Server y trabajar con las bases de datos.

Desde Workbench podremos:

  • crear bases de datos y tablas;
  • ejecutar instrucciones SQL;
  • consultar y modificar datos;
  • comprobar la estructura de las tablas;
  • revisar claves primarias y foráneas;
  • y trabajar con transacciones.

👉 Descargar MySQL Workbench

Recuerda

SQL es el lenguaje que utilizamos para indicar qué queremos hacer.

MySQL Server es el SGBD que almacena los datos y ejecuta las instrucciones.

MySQL Workbench es la herramienta gráfica desde la que trabajaremos con el servidor.

3️⃣ ¿Cómo se organiza el repaso?​

Recorreremos de nuevo el proceso completo, desde el diseño de una base de datos hasta el trabajo con los datos almacenados.

El repaso se divide en cuatro bloques:

  • 0.1 De la realidad a las tablas
    Recuperaremos el modelo E/R, su transformación al modelo relacional y las restricciones.

  • 0.2 Volvemos a hablar SQL
    Recordaremos cómo crear la estructura de una base de datos, insertar datos, consultarlos, modificarlos y eliminarlos.

  • 0.3 Los datos están relacionados
    Volveremos a trabajar con consultas sobre varias tablas, funciones de agregación, agrupaciones y subconsultas.

  • 0.4 Todo o nada
    Recuperaremos el concepto de transacción y el uso de COMMIT y ROLLBACK.

4️⃣ Práctica guiada​

Los ejemplos de los distintos apartados nos servirán para recordar la sintaxis y comprender cada concepto.

Las actividades de aplicación se reunirán en un apartado específico de práctica guiada, en el que trabajaremos sobre un mismo caso práctico.

A partir de ese caso recorreremos de nuevo todo el proceso:

Problema → modelo E/R → modelo relacional → MySQL → datos → consultas → transacciones

La práctica estará organizada de forma progresiva, de manera que cada actividad permitirá aplicar los contenidos recuperados en los distintos apartados de la unidad.

Así podremos trabajar de forma integrada:

  • el diseño de la base de datos;
  • la creación de tablas y restricciones;
  • la inserción de datos;
  • las consultas sobre una y varias tablas;
  • las agrupaciones y subconsultas;
  • la modificación de datos;
  • y el uso de transacciones.
note

Los apartados teóricos se centrarán en recordar y comprender los conceptos.

La práctica guiada será el espacio en el que aplicaremos todo lo aprendido sobre un mismo caso.
